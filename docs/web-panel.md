# Веб-панель MASt3R-SLAM

Панель использует тот же `SlamEngine`, TLS-сервер Android и формат проектов,
что и TUI. Одновременно запускайте только один интерфейс для одной папки проектов.

## Дизайн

Bootstrap 5.3.8 поставляется локально с лицензией MIT. Сборка Node.js и CDN
не нужны. Интерфейс на русском: боковая навигация, название текущего проекта,
предпросмотр обработанного кадра, QR-подключение, сворачиваемый журнал и список проектов.
На узких экранах панели переходят в одну колонку.

Палитра: фон `#111519`, карточки `#181d22`, границы `#2b333b`, акцент `#7ccfaf`.
Шрифт — системный sans-serif. Интерфейс содержит управление и краткое состояние сеанса в заголовке предпросмотра;
отдельных карточек метрик и статуса подключения нет.
Предпросмотр отображает JPEG из движка, а не интерактивную модель PLY.

## Запуск через Compose

Поддерживаемая конфигурация: Linux x86-64, Docker Engine, Compose v2+,
NVIDIA GPU и NVIDIA Container Toolkit. Используется сеть хоста: TLS-сервер
телефона доступен на LAN-адресе компьютера, который указан в QR-коде.
Веб-панель слушает только loopback, по умолчанию `http://127.0.0.1:8080`.

```bash
git submodule update --init --recursive
mkdir -p projects checkpoints
python3 desktop/download_checkpoints.py checkpoints
cp .env.example .env
docker compose up -d --build --wait
```

Сборка CUDA-расширений выполняется внутри контейнера, GPU на стадии сборки
не требуется. Для сборки нужны интернет, существенное свободное место и время;
при запуске GPU обязателен. Веса не включены в образ и монтируются только для чтения.

```bash
docker compose logs -f web
docker compose down
```

Папки `projects/`, `checkpoints/` и `config/` находятся на хосте.
Остановка Compose сохраняет их. Контейнер записывает проекты с UID/GID из
`MAST3R_UID` / `MAST3R_GID` (по умолчанию `1000` / `1000`); задайте свои
значения `id -u` / `id -g`, если они отличаются. `MAST3R_WEB_PORT` и `MAST3R_PHONE_PORT`
меняют порты; `TORCH_CUDA_ARCH_LIST` задаёт архитектуры для сборки.
Не запускайте одновременно TUI и Web: они используют один порт Android и одни проекты.

Для локального запуска в установленном окружении:

```bash
mast3r-slam web
# или
python -m mast3r_slam.cli web
```

## Работа

1. Нажмите «Новый сеанс», введите название проекта и нажмите «Создать». Дождитесь подготовки сеанса и появления QR-кода. Модель нового сканирования
   загружается лениво при первом кадре; при продолжении — из контрольной точки.
2. В Android-приложении подключитесь к компьютеру и запустите сканирование.
3. Следите за предпросмотром, кадрами и задержкой. Панель позволяет поставить
   сканирование на паузу, продолжить его и завершить с сохранением.
4. В «Моих проектах» можно продолжить реконструкцию, скачать PLY и удалить проект
   после подтверждения. Продолжение требует того же телефона и совместимой камеры.

При изменении камеры подтверждение делается на Android. Панель не обходит эту проверку.
Ошибки CUDA, отсутствия весов или загрузки проекта отображаются в интерфейсе;
после исправления причины создайте сеанс заново.

## HTTP API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/health` | Готовность HTTP-панели, без проверки модели/GPU |
| GET | `/api/status` | Состояние, статистика, журнал и токен действий |
| GET | `/api/projects` | Проекты с сохранёнными ревизиями |
| POST | `/api/session` | Новый сеанс: JSON `name` (1–120 символов); для продолжения — `project_id` |
| POST | `/api/commands/{pause,resume,stop}` | Управление активным сканированием |
| GET | `/api/pairing.png` | QR-код текущего сеанса |
| GET | `/api/preview.jpg` | Последний обработанный JPEG |
| GET | `/api/projects/{id}/export` | Потоковое скачивание PLY |
| DELETE | `/api/projects/{id}` | Удаление закрытого проекта |

Записывающие запросы требуют заголовок `X-Panel-Token` со значением `csrf`
из `/api/status`. Это защита от запросов посторонних страниц браузера,
а не вход пользователя. Панель предназначена для локального управления;
не публикуйте её порт в интернете. Телефон использует отдельный TLS-порт
и токен сопряжения, как в TUI.

## Проверка реального движка

Для отдельной проверки GPU без телефона запустите из корня проекта:

```bash
PYTHONPATH=. python scripts/smoke_web_panel.py /path/to/image.jpg
```

Скрипт создаёт временное хранилище, запускает панель на свободном порту,
эмулирует Android-клиент по TLS/Protobuf, отправляет кадр в реальный движок,
получает JPEG-предпросмотр, выполняет паузу и завершение через API панели,
проверяет сохранённую ревизию и скачивание PLY. Временный проект удаляется.
Первый кадр включает загрузку модели и не является замером скорости сканирования.
Эта проверка не заменяет испытание реального Android-приложения и ARCore.
